# Third-party model and data notices

The bundled Core ML model uses TorchVision MobileNetV3-Small ImageNet-1K pretrained weights. TorchVision is distributed under the BSD 3-Clause license; see the [official license](https://github.com/pytorch/vision/blob/main/LICENSE). The repository also includes a separate Pocket Vision fine-tuned checkpoint based on those weights.

The training and evaluation data are Imagenette 2-160, derived from ImageNet. The dataset is not included in this repository. Consult the [Imagenette project](https://github.com/fastai/imagenette) and applicable ImageNet terms before redistributing or using the data.
